## §1 候補履歴 — 0 件時は表示しない

### 1.1 ユーザーの声

- メイン画面下部の **「候補履歴」** ブロック（`#history-panel`）が、**まだ 1 セットもない状態** でも見出し・説明文・空状態メッセージ（「まだ候補がないよ…」）まで表示され、**縦スペースと視線を取る**。
- 初回ログイン直後は **おしゃべり／ウェルカム** に集中したい。**履歴が無いのに履歴エリアがある** のがノイズ。

### 1.2 現行（Phase D）との差分

| 項目 | Phase D v1（現行） | Phase E v1（本要件） |
|------|-------------------|----------------------|
| 履歴 0 件 | `#history-panel` は **常に DOM 上に表示**。`#history-empty` で空文言 | **`#history-panel` 全体を非表示**（見出し・説明・空文言も出さない） |
| タブ | おしゃべり／条件を選ぶの **どちらでも** タブ下に同じ履歴ブロック | **同じ**。0 件なら **どちらのタブでも** 履歴ブロックは出さない |
| 1 件以上 | リスト表示＋折りたたみ（§1.9） | **変更なし**（Phase D §1.9 を維持） |

**Phase D との関係:** §1.9 の H1「タブ下に常時」・H2「0 件時は empty 文言」は、**0 件に限り Phase E で上書き**する。1 件以上は Phase D のまま。

### 1.3 合意した product 決定（v1 草案）

| 項目 | 決定 |
|------|------|
| 非表示単位 | **`#history-panel`（`<section class="history-panel">`）全体** |
| 判定 | クライアントの `plan_history`（API `/api/state` 等と同義）の **length === 0** |
| タブ | **おしゃべりタブ・条件を選ぶタブの両方** で同じルール（履歴はタブ共通の 1 ブロックのため、切替で表示が変わらない） |
| 初回案生成後 | 案 3 つが `plan_history` に 1 件追加されたタイミングで **履歴ブロックを表示**（結果画面 `view-results` から戻ったときも同様） |
| reset | `POST /api/reset` 後 `plan_history` が空 → **再び非表示** |
| 空状態文言 | **表示しない**（ブロックごと消すため `#history-empty` は v1 では不要。DOM に残してよいが常に `hidden` または実装時削除可） |

**「条件タブでも同様」の解釈（v1）:**  
履歴はタブパネルの外（`main-shell` 内・タブ下）に 1 つだけある。**条件を選ぶタブを開いていても**、0 件なら履歴ブロックは **おしゃべりタブと同じく非表示**。条件タブ専用の別履歴はない。

### 1.4 要件 ID

| ID | 要件 |
|----|------|
| E1 | `plan_history.length === 0` のとき `#history-panel` を **非表示**（`hidden` 属性または `display: none` 等。アクセシビリティ上、スクリーンリーダーからも読み上げない） |
| E2 | `plan_history.length >= 1` のとき `#history-panel` を **表示**し、既存のリスト描画・折りたたみ（`HISTORY_COLLAPSE_AFTER`）・コピーを **退行させない** |
| E3 | タブが **おしゃべり / 条件を選ぶ** のどちらでも E1/E2 は **同一**（タブ切替だけでは履歴の出し分けをしない） |
| E4 | **結果画面**（`#view-results`）の案 3 つ・コピー・条件変更は **変更しない**（履歴ブロックはメイン画面のみ） |
| E5 | **API・`plan_history` 構造** は変更しない（表示ロジックのみ） |
| E6 | 履歴非表示中も、Bot の案完成メッセージ（「下の候補履歴にも…」）は **v1 では文言見直し任意** — 実装時に「履歴が無いうちは出さない／初回のみ別文言」へ揃えると UX 一貫（§1.5） |

### 1.5 文案・メッセージ（任意だが推奨）

| 箇所 | 現行 | Phase E 推奨 |
|------|------|----------------|
| `#history-empty` | 「まだ候補がないよ。条件をそろえると…」 | **ブロック非表示のため UI 上は使わない** |
| 案完成 Bot 文（`main.py`） | 「…下の「候補履歴」にも残してあるよ」 | 0 件→1 件目の直前は履歴が見えないため、**「履歴にも残す」は 2 件目以降のみ** または **「メインに戻ると履歴に残る」** などに変更検討（E6） |

※ E6 は **必須ではない** v1 スコープ。ブロック非表示だけ先に入れてもよい。

### 1.6 受け入れ条件（§1 完了の定義）

1. ログイン直後（`plan_history` 空）→ メイン画面に **`#history-panel` が見えない**（おしゃべりタブ）  
2. 上記状態で **条件を選ぶタブ** に切替 → **依然として履歴ブロックは見えない**  
3. 案 3 つを 1 回出す → メインに戻ったとき **履歴ブロックが現れ**、セット #1 が見える  
4. 3 セット超の **折りたたみ・「すべての履歴を見る」** が従来どおり動く  
5. reset 後 → 履歴ブロックが **再び消える**  
6. 結果画面・エクスポート v1 が **退行しない**  

### 1.7 スコープ外（§1）

- 履歴を **別タブ** に移す・ドロワー化  
- 0 件時に **プレースホルダー画像** やバナーで履歴の存在を予告する  
- サーバー側で `plan_history` を返さない
